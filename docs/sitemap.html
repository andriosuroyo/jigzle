How to read this map

Each control is tagged by type. The three status colours are the app's own readiness circles — they recur on every order and stock row.

ButtonPerforms an action (save, advance, delete…)
DropdownA select / picker of preset options
InputText / number / scan field you type into
ToggleSegmented / on-off / sub-tab switch
LinkInline text action (often destructive/secondary)
ModalOpens an overlay / dialog (detailed below it)
To orderLine needs buying — nothing in stock yet
On the wayStock inbound but not yet received
ReadyFully in stock / satisfied

Global · appears on every page

The header, breadcrumb, and auth gate wrap every authenticated screen below.

AppHeader Top bar + navigation Persistent header on every authenticated page — the single source of navigation.

Header controls

  • J logoReturns to the home hub (/).
  • Jigzle Ops titleAlso links to the home hub.
  • Primary nav (desktop)One horizontal bar of the 7 sections in 4 groups (Sales · Warehouse · Database · Tools & Settings). Current section is highlighted.
  • ☰ Menu (mobile)Hamburger toggles a slide-down drawer with the same 4 labelled groups.
  • Sign outEnds the Supabase session and returns to /login. Tooltip shows the signed-in email.

Breadcrumbs

below header

A Home › Section › Tab trail on every section. Home and Section are clickable; the last crumb is the current tab (bold, not a link).

Auth gate (middleware). Every route except /login and /auth/callback is gated: not signed in → redirect to /login; signed in but not on the allow-list → signed out and sent to /login?error=unauthorized. The allow-list lives in one DB table (allowed_users).
/login Sign in The only public screen. Google OAuth, then the allow-list check.
  • Sign in with GoogleStarts Google OAuth, redirecting back through /auth/callback.
  • Unauthorized noticeRed banner "This Google account is not authorized." shown when ?error=unauthorized is present.
/auth/callback — no UI. Exchanges the OAuth code, re-checks the allow-list, then sends you to the home hub (or back to login with an error).
/ Home hub The landing grid — one card per section, built from the same nav config as the header.

Four titled groups of cards. Each card is a link into its section with a one-line blurb:

  • Sales · PurchasingSales group → /sales, /purchasing.
  • Inbound · Outbound · InventoryWarehouse group → /inbound, /outbound, /inventory.
  • Customer · CatalogDatabase group → /customers, /catalog.
  • Data Health · Calculator · Stock Check · SettingsTools & Settings group → the four tool routes.

Sales

The sell-side: turning enquiries into fulfilled, paid orders — and buying the stock to back them.

/sales Sales pipeline One window over the sell-side. Three tabs plus the new-order form.
Pending→ send ready → Fulfill→ to Outbound → History
Legacy redirects. /orders, /pending, /fulfill, /history all forward here (preserving ?tab= / ?order=) for muscle memory and old links.

/inventory Inventory Stock per SKU — on order, being shipped, in warehouse. Single read-only board.

A grid of SKU cards; each shows thumbnail, code/name, and three stat pills (On order · Shipped · Warehouse), plus an "On hold" badge when units are held for a customer.

Database

Merge duplicate customers shared modal

Also opened from Data Health. Folds duplicate records into one keeper.

  • Keep radio · Merge checkboxChoose the keeper and tick records to fold in.

/catalog Catalog Edit SKUs & barcodes; needs-review & shared-barcode cleanup. Three tabs.

Two-pane: left = tabs + list, right = SKU editor or barcode-collision resolver.

Tabs

  • AllSearch-driven (code / name / barcode); rows open the SKU editor.
  • Needs review (N)SKUs flagged incomplete (missing name / brand / type / piece count).
  • Shared barcodes (N)Barcodes owned by more than one SKU (collisions).

Right pane · SKU editor

  • SKU fieldsIdentity, classification, dimensions/weight, media/tags (code & dates read-only).
  • verifiedPer barcode: toggle verified (immediate save).
  • unlinkRemoves a barcode from the SKU.

Right pane · collision resolver
